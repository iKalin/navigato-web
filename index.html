Q4 2026 90-day EV Infrastructure Intelligence Pilot

A low-risk route for Mission Cities to validate value before procurement.

  1. Connect or model — Selected charging sites, CSV data, read-only API access or simulated city network.
  2. Analyse — Utilisation, peak demand exposure, pricing, grid constraints and ESG signals.
  3. Simulate — Baseline vs optimised scenarios, flexibility readiness and investment cases.
  4. Deliver — Pilot dashboard, ESG summary, procurement-ready report and scale roadmap.

Success criteria: Identified optimisation opportunities, flexibility readiness assessment, ESG evidence workflow, procurement-ready deployment roadmap, and market-readiness foundation for future VPP participation.

Hybrid cloud by design

Navigato AI is designed as a hybrid Azure + GCP platform.

Azure

  • Public-sector deployment
  • Identity and access control
  • API governance
  • Secure hosting
  • Monitoring and reporting
  • Administration integration

GCP

  • BigQuery analytics
  • Data lake architecture
  • Vertex AI
  • Large-scale telemetry
  • Simulation workloads
  • Predictive optimisation

Azure for trust, governance and public-sector integration. GCP for AI-scale data processing, simulation and predictive optimisation.

Trust and governance by design

  • Human-in-the-loop approval
  • Audit logs
  • Role-based access
  • Data ownership clarity
  • Secure API architecture
  • Compliance-aligned reporting
  • Market execution limits
  • Licensed partner execution for real energy trading
  • Simulation vs real data labelling

During pilot phase, Navigato AI operates as a decision-support and simulation layer. No autonomous infrastructure control or energy market execution is performed without explicit operator approval and the appropriate licensed market framework.
